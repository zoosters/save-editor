# Save editor

Edit *Madagascar* (2005, PC) saves in the browser: progress, player, Zoovenir shop, level records, minigame high scores and collectibles. Works with saves from the original game and from Zoosters. Your save never leaves your machine.

**[Open the editor](https://zoosters.github.io/save-editor)**
